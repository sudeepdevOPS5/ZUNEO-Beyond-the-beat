# Security Policy

## Supported Versions

Only the latest release (and current main build) are supported with security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/sudeepdevOPS5/ZUNEO-Beyond-the-beat/security/advisories/new) for this repository.

Include:
- A description of the vulnerability and its impact.
- Steps to reproduce.
- The app version/build you tested on.

We will acknowledge reports promptly and aim to ship a fix before any public disclosure.

## Scope

This covers the ZUNEO Android app and the code in this repository. It does not cover third-party services the app connects to (YouTube Music, Spotify, Discord, Last.fm, etc.) — report issues in those services to their respective providers.
